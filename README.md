# Qt5 C++ GUI Development for Beginners: The Fundamentals

This repository contains all my practical projects, assignments, and source code developed during the course **"Qt5 C++ GUI Development for Beginners: The Fundamentals"**. 

The goal of this repository is to track my learning progress as I master cross-platform GUI development using C++ and the Qt 5 framework, moving from fundamental core concepts to advanced desktop application features.

---

## 🛠️ Tech Stack & Requirements

* **Framework:** Qt 5.12.4
* **Compiler:** MinGW 32-bit / 64-bit
* **IDE:** Qt Creator
* **Language:** C++ (Modern Standards)
